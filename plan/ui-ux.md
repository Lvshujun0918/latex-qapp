# 前端 UI/UX 设计文档（Ionic Vue + Capacitor）

## 1. 文档目标
本文件用于定义 AI 错题本 App 的前端体验规范，覆盖：
- 信息架构（IA）
- 页面清单与核心交互
- 组件规范与设计约束
- 离线/同步反馈策略
- AI 解析与 LaTeX/PDF 相关交互

本设计严格对齐 `plan.md` 的 MVP 范围，不扩展额外角色与复杂功能。

---

## 2. 设计原则
1. **移动优先**：Android 首发，单手操作优先。
2. **任务闭环优先**：录题 → AI 解析 → 复习 → 导出 PDF 为主路径。
3. **离线优先**：无网也能录入和查看；联网后补充同步与 AI。
4. **低学习成本**：页面结构稳定、按钮语义明确、减少层级跳转。
5. **反馈可见**：所有异步任务（AI、同步、PDF）必须有状态反馈。

---

## 3. 信息架构（IA）
采用底部 4 Tab + 全局浮动入口（新增错题）：

- Tab1：`错题`（首页）
- Tab2：`复习`（推荐与计划）
- Tab3：`统计`
- Tab4：`我的`（账号、同步、导出记录）
- 全局 FAB：`+ 录入错题`

二级页面：
- 登录/注册
- 错题详情
- 编辑错题（含 LaTeX 编辑）
- AI 解析详情
- PDF 导出配置
- PDF 任务详情

---

## 4. 核心用户流程

## 4.1 首次使用流程
1. 启动 App
2. 快速注册（仅用户名+密码，无email/phone验证）或登录
3. 进入错题首页（空状态引导）
4. 点击 FAB 录入第一道题

## 4.2 错题录入流程（MVP 主路径）
1. 选择录入方式：拍照 / 相册 / 手动输入
2. 填写基础信息：学科、题型、难度、错因
3. 保存到本地 SQLite（立即成功）
4. 若在线：提示可立即 AI 解析；若离线：提示“已保存，联网后可解析”

## 4.3 AI 解析流程
1. 从错题详情点击“生成 AI 解析”
2. 展示分析中状态（骨架屏 + 可取消）
3. 返回结构化结果：
   - 解题步骤
   - 易错点
   - 复习建议
   - 知识点标签
4. 用户可“采纳建议并加入复习”

## 4.4 LaTeX 与 PDF 流程
1. 在错题编辑页查看/修订 `LaTeX` 源码
2. 保存后标记渲染状态（成功/失败）
3. 在“我的 > 导出错题本”选择筛选条件
4. 提交 PDF 任务，进入队列
5. 任务完成后提供下载/分享

## 4.5 离线同步流程
1. 离线录题标记“待同步”
2. 网络恢复自动触发同步（也支持手动）
3. 同步结果 toast：成功/部分失败/冲突
4. 冲突时进入冲突详情页做确认（MVP 可先默认 LWW 并提示）

---

## 5. 页面清单与布局规范

## 5.1 登录/注册页（AuthLogin）
- 组件：用户名输入、密码输入、登录按钮、注册入口
- 注册简化：仅需用户名+密码，无需email/phone验证（节约注册成本）
- 状态：加载中、失败提示、离线提示
- 规则：登录按钮需在字段合法时可点

## 5.2 错题列表页（ErrorList）
- 顶部：搜索框 + 学科筛选 + 同步状态点
- 主体：错题卡片列表
- 卡片字段：题目缩略图、标题/首行文本、学科、难度、同步状态
- 空态：插图 + “立即录入”按钮
- 固定 FAB：新增错题

## 5.3 新增/编辑错题页（ErrorEditor）
- 模块：图片预览区（识别前临时显示）、LaTeX编辑区、元信息区、提交区
- **数据流程**：拍照→AI视觉识别→生成LaTeX→仅存储LaTeX（不保留原图）
- 元信息：学科、题型、难度、错因、知识点（可选）
- CTA：`保存到本地`、`保存并AI解析`
- 校验：LaTeX内容不为空

## 5.4 错题详情页（ErrorDetail）
- 展示：题目内容（LaTeX渲染结果，无原图存储）
- 操作：编辑LaTeX、删除、AI深度解析、加入复习
- 信息：同步状态、最近复习时间、掌握度
- **注意**：页面仅显示LaTeX渲染结果，原图已在识别后删除

## 5.5 AI 解析页（AnalysisDetail）
- 分区：解题步骤、错因分析、建议动作、知识点
- 操作：重新解析、收藏解析、加入复习计划
- 异常：解析失败可重试

## 5.6 复习页（ReviewHome）
- 模块：今日推荐、高频错题、知识点薄弱项
- 卡片点击进入对应错题详情
- 提供“完成复习”快捷反馈

## 5.7 统计页（Stats）
- 模块：总错题数、学科分布、掌握度趋势
- 图表：轻量图（柱状/折线）
- 时间筛选：7天 / 30天 / 全部

## 5.8 我的页（Profile）
- 模块：账号信息、同步中心、导出记录、设置
- 操作：手动同步、查看同步日志、退出登录

## 5.9 PDF 导出页（PdfExport）
- 条件：学科、时间范围、难度、是否仅未掌握
- 模板：默认模板（MVP 单模板）
- 提交后跳转任务详情

## 5.10 PDF 任务详情页（PdfJobDetail）
- 状态：排队中/生成中/成功/部分成功/失败
- 明细：成功题数、失败题数、错误摘要
- 操作：下载、重新生成

---

## 6. 组件系统（Ionic）
优先使用 Ionic 原生组件，减少自定义复杂度。

- 页面容器：`IonPage` + `IonHeader` + `IonContent`
- 列表：`IonList` + `IonItem` + `IonLabel`
- 卡片：`IonCard`
- 输入：`IonInput` / `IonTextarea` / `IonSelect`
- 操作按钮：`IonButton` / `IonFab`
- 标签与状态：`IonChip` / `IonBadge`
- 弹层：`IonModal` / `IonAlert` / `IonActionSheet`
- 反馈：`IonToast` / `IonLoading` / `IonSkeletonText`
- 导航：`IonTabs` + `IonTabBar`

组件规则：
1. 同一语义使用固定组件组合（避免风格漂移）
2. 主按钮仅一个（页面唯一主行动）
3. 危险操作（删除）必须二次确认

---

## 7. 视觉与交互规范

## 7.1 视觉层级
- 一级信息：标题、主按钮、关键状态
- 二级信息：元数据（学科、难度、时间）
- 三级信息：辅助说明、空态文案

## 7.2 状态颜色语义
- 成功：同步成功、任务完成
- 警告：离线、部分成功
- 错误：解析失败、同步失败、PDF 失败
- 中性：待处理、排队中

> 具体颜色值由 Ionic 主题 token 管理，不在文档中硬编码。

## 7.3 动效与反馈
- 页面切换使用默认 Ionic 动画
- 异步请求必须显示加载态
- 完成后给出 toast（2~3 秒）
- 失败反馈含“原因 + 重试入口”

---

## 8. 关键状态机（前端）

## 8.1 错题同步状态
- `pending`：待同步
- `syncing`：同步中
- `synced`：已同步
- `conflict`：冲突
- `failed`：失败

展示规则：
- 列表卡片右上角展示状态徽标
- 详情页展示最近同步时间
- “我的>同步中心”可查看失败/冲突明细

## 8.2 AI 任务状态
- `idle`、`running`、`success`、`failed`

## 8.3 PDF 任务状态
- `queued`、`running`、`success`、`partial`、`failed`

---

## 9. 离线与弱网 UX 规范
1. 录题保存优先写本地，不阻塞用户流程
2. 无网时隐藏或置灰“立即 AI 解析”，给出说明
3. 自动同步失败不打断操作，仅提示并记录到同步中心
4. 手动同步提供明确结果统计：成功X条/失败Y条
5. 弱网下重试采用指数退避，避免频繁弹窗

---

## 10. LaTeX 体验规范
1. 编辑区采用“源码编辑 + 预览”双区模式（MVP 可先切换查看）
2. 保存 LaTeX 后立即进行渲染状态检查（本地仅标记，服务端最终校验）
3. 渲染失败时高亮错误并允许继续保存（不阻塞错题保存）
4. 错题详情优先展示渲染结果，失败时回退纯文本

---

## 11. 可用性与无障碍
- 触控目标建议不小于 44x44
- 表单错误信息靠近字段显示
- 关键按钮提供禁用态与原因说明
- 文案使用学生可理解语言，避免技术术语

---

## 12. 埋点与数据指标（前端侧）
MVP 建议埋点：
- 新增错题成功率
- AI 解析触发率与成功率
- 同步成功率/冲突率
- PDF 发起率与成功率
- 日活用户的“录题→解析→复习”转化率

---

## 13. 页面到接口映射（MVP）
- 登录页 → `POST /api/auth/login`
- 错题列表页 → `GET /api/records`
- 新增/编辑页 → `POST /api/records` / `PUT /api/records/:id`
- AI 解析页 → `POST /api/ai/analyze` + `GET /api/ai/analysis/:recordId`
- 同步中心 → `POST /api/sync/push` + `POST /api/sync/pull`
- PDF 导出页 → `POST /api/pdf/export`
- PDF 任务页 → `GET /api/pdf/jobs/:jobId`

## 15. MVP 范围边界（不做）
- 教师/家长端协同
- 多人共享题库编辑
- 多模板皮肤化系统
- 复杂动画与重度个性化设置

以上功能在后续版本按优先级追加。
